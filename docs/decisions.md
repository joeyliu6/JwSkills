# 决策与踩坑

> 验证过的才写进来。猜测、纯咨询和原始对话不写。

## 决策

| 日期 | 决定了什么 | 为什么 | 放弃了什么 |
|------|-----------|--------|-----------|
| 2026-08-15 | `.gitignore` 从整目录忽略 `.claude` 改为只忽略 `settings.local.json`、`.structure-state.json`、`skills/` | 整目录忽略会连 hook 和 `settings.json` 一起挡掉，等于 `init-project` 教别人的做法在本仓库自己身上不成立 | 无 |
| 2026-08-15 | `.claude/skills/`（工作副本）不进版本控制 | 与 `skills/` 内容重复，每次改技能会在 git 里留两份一样的 diff | 换机器 clone 后要先跑一次 bootstrap 复制，否则本仓库加载不到技能 |
| 2026-08-15 | `CLAUDE.md` 取消忽略，提交进仓库 | 双目录同步规则是贡献者最容易踩的坑，不提交外人看不到 | 无 |
| 2026-08-15 | hook 用 Node 实现，而非技能里建议的 pwsh / bash | 本仓库无任何运行时标志文件；pwsh 5.1 是 Windows 独有，bash 解析 JSON 需要 jq；hooks.md 参考实现本身是 Node 版，照搬零翻译风险 | 没装 node 的协作者 hook 会静默失效（fail-open，不阻断） |
